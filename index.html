From blank deck to final report.

Every session follows the same four moves, and attendees only ever see the one that matters: the question in front of them.

  1. Build

    Assemble a deck of polls, trivia, word clouds, ratings, open Q&A and slides in any order. Or have AI draft questions from a topic.

  2. Start

    Starting a session gives you a five-character code and a QR code to put on the big screen.

  3. Run

    Open one item at a time. Votes land live beside a preview of exactly what attendees see. Press Space to move on.

  4. End and export

    Ending a session builds a report and exports your data, then clears it from the live system.

AI is optional

Speed Card drafts a batch of questions and Improve Wording tightens one you wrote. Both use your own free Groq key, stored only on your device.

Nothing lingers

Session data lives in the live database only while the session runs. Export it when you end, and it is cleared.
